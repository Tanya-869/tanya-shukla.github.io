Tanya Shukla Portfolio

A visually stunning, futuristic portfolio website built for internship applications.

Simply open `index.html` in any modern browser. No build step required.

For deployment:
1. Upload all 3 files (`index.html`, `styles.css`, `script.js`) to any static host
2. Add your actual resume PDF as `resume.pdf` in the same folder
3. Replace placeholder GitHub/LinkedIn URLs if needed



index.html   — HTML structure
styles.css   — All styles, animations, themes
script.js    — Interactions: particles, typing, cursor, scroll, tilt, form
